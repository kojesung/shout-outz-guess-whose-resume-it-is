# 이 이력서, 어느 팀 걸까요?

shout-outz 부스에서 쓰는 퀴즈 화면이다. 방문자의 팀을 듣고 그 팀의 경험(이력서 문장)을 팀 이름을 가린 채 보여 준 뒤, 어느 팀인지 맞히게 한다.

## 진행 방법

1. 첫 화면(진행자 화면)에서 팀 이름이나 크루 닉네임으로 팀을 찾는다. 방문자에게는 보여 주지 않는다.
2. 직군(백엔드·프론트엔드·안드로이드)을 누르면 문제 화면이 열린다. 주소에는 팀 이름 대신 코드만 들어간다.
3. 문제 화면에서는 팀 이름이 `■■■`로 가려지고 출처는 누를 수 없다.
4. `정답 보기`를 누르면 가림이 풀리고, shout-outz의 그 팀 페이지(`https://shout-ou.tz/projects/@slug`)가 새 탭으로 열린다.
5. `← 다음 방문자`로 진행자 화면으로 돌아간다.

## 데이터

서버 없이 `src/data/projects.json`만 읽는다. 운영 API에서 새로 받으려면 아래 명령을 실행하고 다시 배포한다.

```bash
pnpm fetch-data
```
